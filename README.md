# NK-STATS — 북한·탈북 담론 텍스트 코퍼스 & 프레임 분석

KBS 〈남북의 창〉 방송 스크립트와 탈북민·북한 전문 유튜브 채널 자막을 수집하고,
북한을 둘러싼 미디어 담론의 **종단(연도) 변화**를 분석하는 연구 프로젝트입니다.

## 개요

| 매체 | 단위 | 규모 |
|------|------|------|
| KBS 〈남북의 창〉 | 방송 코너(섹션) 스크립트 | 2018·2020·2022·2024 / 약 1,993섹션 |
| 유튜브 | 영상별 자막 전문 | 6개 채널 / 595편 (2018·2024) |

## 저장소 구성 (코드·방법론만 공개)

원본 데이터(방송 스크립트·유튜브 자막)는 **저작권상 배포가 제한**되어 이 저장소에는
**수집·분석 코드, 어휘집(YAML), 방법론 보고서**만 포함합니다. 데이터는 아래 스크립트로 재수집할 수 있습니다.

```
research/
├── kbs/                        KBS 〈남북의 창〉
│   ├── collect_kbs_year.py       연도별 크롤러(Selenium)
│   ├── add_speaker.py            화자(speaker)·층위(layer) 재구성
│   ├── build_master.py           마스터 테이블(sections/articles) 구축
│   ├── referent_lexicon.yaml     지칭어 통제어휘집
│   ├── referent_analysis.py      지칭어 점유율·부트스트랩
│   └── reporting_verbs.yaml      보도동사 태도 분류
├── youtube/                    유튜브 자막 수집 파이프라인
│   ├── build_manifest*.py         재생목록·업로드일 매니페스트
│   └── collect_subs*.py           yt-dlp 자막 수집·정제
├── kiwi_user_dict.tsv          Kiwi 형태소 북한어 사용자 사전
└── 데이터수집_보고서.md          수집·구축·예비분석 보고서
```

## 방법론 요약

- **KBS**: 매주 토요일 방송의 코너별 스크립트 추출, 제외 규칙(영상 전용 코너) 적용, 4개 연도 동일 규칙.
- **유튜브**: `yt-dlp`로 실제 업로드일 기준 연도 선별 후 자막(vtt→텍스트) 수집. 대상 채널 자막은 100% 자동생성.
- **정제**: `section_type` 라벨을 그대로 쓰지 않고 화자(앵커/리포트/취재진/외부관료/외부전문가)를 재구성,
  인용 구간을 `quote_spans`로 마킹.
- **분석**: 지칭어 점유율, 보도동사 거리두기, 헤지(확신도) 등을 기사 단위·부트스트랩·경향검정으로 산출.

## 주요 발견 (예비)

- **남측 지칭 프레임 전환**: 관계어 '남측'→국가명 '한국' 이동. 2022년(정부 교체 시점) 전후로 국소화(유의).
- **태도(거리두기)**: 유의한 시계열 변화 없음 — 지칭 변화가 일반 논조 변화의 부산물이 아님을 뒷받침.
- **확신도(헤지)**: 북한 내부 소재에서만 유의하게 상승 — 정보 접근 악화(2020 봉쇄 이후)의 흔적으로 식별.

자세한 내용은 [`research/데이터수집_보고서.md`](research/데이터수집_보고서.md) 참조.

> ⚠️ 수집 데이터는 학술 연구(공정이용) 목적이며 원문의 외부 배포를 제한합니다.
